Consentimiento de procesamiento de datos

Al iniciar la verificación de edad para Hogar Feliz Rewards, aceptas que el proveedor especializado de verificación procese los datos necesarios para comprobar si cumples el requisito de 18 años, conforme a sus condiciones y política de privacidad.

Hogar Feliz utilizará el resultado mínimo de la verificación únicamente para decidir si puedes continuar con el proceso de autorización de Rewards.

Hogar Feliz no pretende recibir ni almacenar documentos de identidad, selfies, vídeos o plantillas biométricas utilizadas por el proveedor.

La verificación es voluntaria. Si cancelas o no superas la comprobación, no se concede autorización adulta para Rewards.
